Recommended Refactoring (Pure Python)

If you want to keep the script in pure Python, here is how you can update the dot_product function to be more idiomatic:

def dot_product(vector_a, vector_b):
    """Return the dot product of two vectors."""
    # zip() pairs up the elements, and sum() adds the results of the multiplication
    return sum(a * b for a, b in zip(vector_a, vector_b))
